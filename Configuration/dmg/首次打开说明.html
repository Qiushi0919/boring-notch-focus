Boring Notch Focus

首次打开说明 / First Launch Guide

简体中文

  1. 先将 Boring Notch Focus 拖入“应用程序”文件夹，不要直接在 DMG 中运行。
  2. 从“应用程序”文件夹启动。首次启动会先显示语言选择，然后进入权限中心。
  3. 只需为你要使用的功能授予权限；以后可以在“设置 → 权限中心”重新检查。

如果 macOS 阻止打开，请进入“系统设置 → 隐私与安全性”，找到 Boring Notch Focus 并点击“仍要打开”。

English

  1. Drag Boring Notch Focus to Applications. Do not run it directly from the DMG.
  2. Launch it from Applications. The first launch starts with language selection, followed by Permission Center.
  3. Grant only the permissions needed by the features you use. You can check them again under Settings → Permissions.

If macOS blocks the app, open System Settings → Privacy & Security, find Boring Notch Focus, and click Open Anyway.
