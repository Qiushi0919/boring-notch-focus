# Boring Notch Focus 1.0.0

首个可分享的定制版本。

- 新增刘海屏番茄钟与专注设置。
- 增强多播放源音乐控制、切歌提示和收藏状态。
- 改进日历日程展示与提醒事项读取。
- 改进文件岛拖放、Word 文档接收、快速预览、选择删除和一键清空。
- 增加简体中文界面文案。
- 使用独立的 Boring Notch Focus 更新通道，后续版本可在应用内自动更新。

这是基于 Boring Notch 的 GPLv3 修改版，并非官方构建。

## 首次安装

1. 打开 DMG，把“Boring Notch Focus”拖到“Applications/应用程序”。
2. 从“应用程序”文件夹启动，不要直接在 DMG 中运行。
3. 按提示授予日历、提醒事项和辅助功能权限。
4. 如果 macOS 首次拦截应用，请在“系统设置 → 隐私与安全性”中选择“仍要打开”。

安装完成后，后续版本会通过应用内更新器自动推送，不需要重新下载 DMG。
