首次安装

  1. 打开 DMG。
  2. 把“Boring Notch Focus”拖到“Applications/应用程序”，不要直接在 DMG 中运行。
  3. 从“应用程序”启动，先选择语言，再进入权限中心。
  4. 只授予所使用功能需要的权限；以后可以在“设置 → 权限中心”重新检查。

如果 macOS 首次拦截应用，请在“系统设置 → 隐私与安全性”中选择“仍要打开”。

完成首次安装后，后续版本将由应用内置的 Sparkle 更新器自动推送，不必再次下载 DMG。

English: Drag the app to Applications, launch it, choose a language, and use Permission Center to grant only the permissions you need.
