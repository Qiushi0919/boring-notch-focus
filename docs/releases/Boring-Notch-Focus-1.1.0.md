# Boring Notch Focus 1.1.0

本版本改进首次安装和权限管理体验。

- 首次启动时先选择“跟随系统、简体中文或 English”。
- 新增统一权限中心，显示日历、提醒事项、QQ 音乐控制、系统 HUD、通知、相机和音乐自动化的用途与授权状态。
- 可以直接请求权限、打开对应的系统设置，并随时重新检测状态。
- 设置侧边栏新增“权限中心”，安装后仍可重复打开。
- 设置中新增语言选项；切换语言后应用自动重启并完整应用新语言。
- 系统权限说明改为中英双语。
- DMG 新增中英双语首次打开说明，包含 macOS“仍要打开”操作。

这是基于 Boring Notch 的 GPLv3 修改版，并非官方构建。

## First launch

1. Drag Boring Notch Focus to Applications.
2. Launch it from Applications and choose a language.
3. Use Permission Center to grant only the permissions required by the features you use.
4. If macOS blocks the app, open System Settings → Privacy & Security and choose Open Anyway.

已安装 1.0.0 的用户会通过应用内更新器收到本版本，不需要重新下载 DMG。现有用户可从“设置 → 权限中心”打开新页面。
